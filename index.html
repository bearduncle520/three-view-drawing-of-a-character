各平台获取 API Key 与端点
阿里百炼（通义千问视觉模型）
① 打开 阿里云百炼控制台 → 右上角选择「华北2（北京）」地域
② 左侧导航「API Key 管理」→ 点击「创建 API Key」→ 设置权限后确认
③ 弹窗中复制 API Key 并妥善保存（关闭后无法再次查看）
API 端点：https://dashscope.aliyuncs.com/compatible-mode/v1
支持模型：Qwen3.7-Plus（2026.06）/ Qwen-VL-Max（2025.08）/ Qwen-VL-Plus（2025.03）/ Qwen-VL-Flash（2025.01）/ Qwen3-VL-32B-Instruct（2025.05）
Kimi（月之暗面）
① 打开 Kimi 开放平台控制台 → 登录账号
② 左侧「API Keys」→ 点击「Create API Key」
③ 填写名称后创建 → 复制 API Key 并妥善保存
API 端点：https://api.moonshot.ai/v1
支持模型：Kimi-K2.5（多模态视觉旗舰，2026.01）
腾讯混元
① 打开 腾讯云控制台 → 访问管理 → API 密钥管理
② 登录后点击「新建密钥」→ 生成 SecretId 和 SecretKey
③ 复制 SecretId 并作为 API Key 填入（混元 API 使用 SecretId 认证）
API 端点：https://api.hunyuan.cloud.tencent.com/v1
支持模型：Hunyuan-Vision（视觉理解）/ Hunyuan-Vision-1.5-Thinking（视觉推理增强，2025.10）
豆包（火山引擎）
① 打开 火山引擎方舟平台 → API Key 管理
② 登录后点击「创建 API Key」→ 复制生成的 Key
③ 在「模型推理」中开通 Doubao-Vision-Pro-32k 或 Doubao-1.5-Pro-32k 的推理接入点
API 端点：https://ark.cn-beijing.volces.com/api/v3
支持模型：Doubao-1.5-Pro-32k（多模态视觉，2025.01）/ Doubao-Vision-Pro-32k（视觉理解专用）
智谱 AI
① 打开 智谱 AI 开放平台 → 个人中心 → API Keys
② 登录后点击「添加 API Key」→ 选择权限后确认
③ 复制生成的 API Key 并妥善保存（格式：xxxx.xxxx）
API 端点：https://open.bigmodel.cn/api/paas/v4
支持模型：GLM-4V-Flash（免费）/ GLM-4V-Plus（2025.07）/ GLM-4V-Plus-0111（2025.01）/ GLM-4.6V（2025.12）/ GLM-4.1V-Thinking / GLM-5V-Turbo（2026.04）/ GLM-5.2（旗舰，1M上下文）
自定义
① 自行配置 API Key
② 自行填写 API 端点地址
③ 模型名称在模型下拉框中直接输入自定义值
API Key 安全说明
1. 你填入的 API Key 和端点仅保存在 localStorage 中，不会写入硬盘或 Cookie；
2. 配置信息仅发送至你指定的 API 端点用于身份验证，不会上传至任何第三方服务器；
3. 普通刷新（F5 / Ctrl+R）不会清空配置，可继续使用；
4. 关闭标签页后重新打开，配置依然保留，无需重复填写；
5. 点击上方「清空配置」按钮即可手动清除配置；强制刷新（Ctrl+F5 / Ctrl+Shift+R）不会清除已保存的配置，可放心使用。
