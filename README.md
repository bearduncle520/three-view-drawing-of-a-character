# 角色一致性形象图 - 三视图生成工具

纯静态页面，基于设计参考图还原的深色科技风 AI 角色形象图生成工具界面。

## 使用方式

直接用浏览器打开 `index.html` 即可，无需任何服务端环境。

## 功能

- 配置 AI 模型（API 提供商选择、模型选择、API Key、端点配置）
- 上传角色参考图（拖拽或点击）
- 画风分析结果编辑（风格、质感、比例体系）
- 构图排版引擎选择（经典宽幅 / 特写补丁）
- 提示词生成与复制
